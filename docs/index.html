Four tracks, a drum synth and a small cast of characters for your FM-1.

KARMA is free custom firmware for the M-VAVE FM-1. An acid bass or a Juno, physical modelling, two dozen synthesis models, a drum synthesizer, a 64-step sequencer and generators that keep writing while you play. It runs in your browser today.

INSIDE

Four tracks, each with its own engine

Every track plays at once from the same 64-step sequencer. Each one keeps its colour across the screens, the LEDs and this page.

TRACK 1

ACID or JUNO

303 voice from X0X · Juno voice from FM-106

ACID is a TB-303 voice with accents and slides. JUNO is a Juno-106 style polysynth: DCO, an IR3109-style ladder filter and BBD chorus, up to six voices.

TRACK 2

ELEMENTS

Built on Mutable Instruments' open-source Elements code

Physical modelling. Strike, pluck, bow or blow a modal resonator and shape its body. The Ominous Voice is in here too.

TRACK 3

PLAITS

Built on Mutable Instruments' open-source Plaits code

24 synthesis models: virtual analog, waveshaping, FM and 6-op FM, grain, wave terrain, string machine, chiptune, strings, modal, speech, particle and analog drums.

DRUM

HEX drum synth

An LXR-style drum synthesizer, no samples

Kick, snare, clap, cymbal and hat models, synthesised as they play. Several kits ship with it, plus four user kits for your own.

SEQUENCER

64 steps per track

  • Chords of up to 4 notes on a step
  • Ratchets, accents, slides
  • A chance condition per step
  • PLAY modes: forward, reverse, pendulum, random, walk, chance, jump, stride
  • A song arranger to chain sections
GENERATORS

Loops that write themselves

  • GEN writes each synth track's part and keeps it evolving as it plays. Press a key on its page and the whole band moves to that key.
  • ACID GEN writes acid lines with the TB-3PO generator.
  • DRUM GEN reads a Grids-style drum map with X/Y and a density per lane, or makes Euclidean rhythms.
HARMONY

One key for the whole band

  • Set a KEY, a MODE and a chord PROGRESSION, and every GEN track follows it.
  • Each track plays its role: an acid bass on the roots, a voice-led line of chord tones, a lead motif that develops over four bars.
EFFECTS

CLOUD, reverb, delay, punch-in

  • CLOUD, a granular effect built on the open-source code of Mutable Instruments' Clouds, as a send from each track and each drum sound
  • Reverb and delay
  • Punch-in performance effects held on the keys: loops, stutter, filters, freeze and more
USB

Audio interface and MIDI

  • Class-compliant stereo USB audio at 44.1 or 48 kHz
  • USB MIDI in and out
  • Per-track STEMS over USB: coming next, in progress
CONTROLLERS

Bring your own knobs

  • Map a MIDI controller to the FM-1's eight rotaries. An Akai MPK mini's eight knobs line up one to one.
  • In the simulator, Web MIDI works when you run it from your own computer.
CHARACTERS

Every screen has somebody on it

The pixel art is drawn for KARMA, in the spirit of the OP-1's playful screens. The characters react to the notes you play. These are real screens, rendered from the firmware.

FAQ

Before you install

Can I go back to the official firmware?

Yes. The installer will offer M-VAVE's official V15 firmware alongside KARMA, so going back is the same few clicks as going forward.

What do I need to install it?

Chrome or Edge on a computer (the installer uses WebUSB, which other browsers do not offer), and a USB cable that carries data. Many cables that come with chargers only carry power, and the FM-1 will not show up with one of those.

I run FM1 Open or another custom firmware. What should I do?

Return to the official V15 firmware first, then install KARMA from there. Going from one custom firmware straight to another is not tested.

When can I install it?

After hardware testing. The first FM-1 unit arrives in a few days, and the installer opens once KARMA has been checked on it. Until then, the browser simulator runs the same firmware.

Does it cost anything?

No. KARMA is free and will stay free. It is licensed GPL-3.0-only, the source is public, and it is never for sale.

Can I use it as an audio interface?

Yes. Over USB the FM-1 shows up as a class-compliant stereo audio interface at 44.1 or 48 kHz, and as a MIDI device. Separate stems per track are being built now.
